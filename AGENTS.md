## Agent skills

### Skill maintenance

When creating or editing skills, shared instructions, or skill templates in this repository, load the installed `writing-for-agents` skill and its skill-mechanics reference where applicable. Use its context-pointer and progressive-disclosure guidance while preserving explicit user customizations, authorization boundaries, and workflow completion criteria.

### Issue tracker

Issues live in GitHub Issues; external pull requests are not a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

Canonical triage roles use their default label names. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repository. See `docs/agents/domain.md`.
